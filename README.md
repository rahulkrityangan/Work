# Practice Git with VS Code

Welcome to this Git practice repository! This resource is designed to help you learn and practice Git commands and workflows using Visual Studio Code.

## Overview

This repository contains materials and exercises for practicing Git version control fundamentals and advanced concepts.

## Getting Started

### Prerequisites
- Visual Studio Code installed
- Git installed on your local machine
- Basic command line/terminal knowledge

## Contents

This practice repository includes:
- Git fundamentals exercises
- Branching and merging practice
- Commit and history navigation
- Conflict resolution exercises
- Collaboration workflows

## Git Commands to Practice

### Basic Commands
```bash
git init              # Initialize a new repository
git add               # Stage changes
git commit            # Create a commit
git status            # Check repository status
git log               # View commit history
```

### Branching
```bash
git branch            # List or create branches
git checkout          # Switch branches
git merge             # Merge branches
git rebase            # Rebase branches
```

### Remote Operations
```bash
git push              # Push commits to remote
git pull              # Pull changes from remote
git fetch             # Fetch updates from remote
git clone             # Clone a repository
```

### Undoing Changes
```bash
git restore           # Restore files
git revert            # Revert commits
git reset             # Reset to previous state
```

## Tips for Learning

1. **Start Simple**: Begin with basic commands before moving to advanced topics
2. **Use the Terminal**: Practice in the integrated terminal within VS Code
3. **Visualize**: Use VS Code's Source Control panel to understand changes
4. **Experiment**: Don't be afraid to make mistakes in a practice repository
5. **Reference**: Keep Git documentation handy for command syntax
